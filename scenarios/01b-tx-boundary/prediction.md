# 01b 決済 API をトランザクションの外で呼ぶ

01a に加えて、決済 API の呼び出しをトランザクションの外に出し、HikariCP の取得待ちを 250ms（設定できる最小値）にする。

## 予測

- コネクションを握るのは DB に書く数ミリ秒だけになり、必要なコネクション数は 1 未満
- スレッドの L は 60 × 0.3 + α ≈ 19 で、上限 40 に収まる
- /orders は 0.3 秒でタイムアウトして 504 を返し、/products は影響を受けない
- 再起動は起きず、遅延を外せばすぐに元に戻る

## 合格条件

- 障害中のスレッドの最大値が 30 未満
- 障害中の /products の成功率が 99% 以上
- 再起動 0 回、回復まで 10 秒以内
