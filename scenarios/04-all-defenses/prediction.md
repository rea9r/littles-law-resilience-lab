# 04 すべての防御

タイムアウト 300ms、決済 API はトランザクションの外、HikariCP の取得待ち 250ms、Bulkhead 12、Retry は最大 2 回試行で間隔 100ms、CircuitBreaker あり。

## 予測

- サーキットブレーカーが open になるまでの間も、バルクヘッドが 決済 API の呼び出しを 12 件に抑える
- /products は影響を受けず、/orders はすぐに失敗を返す
- 遅延を外すと数秒で元に戻る

## 合格条件

- 障害中のスレッドの最大値が 30 未満
- 障害中の /products の成功率が 99% 以上
- 再起動 0 回、回復まで 15 秒以内
